CNN pour SkylandersCNN for Skylanders

Projet PersonnelPersonal project

L'idée était de créer un réseau de neurones capable d'identifier le type d'un Skylanders d'après une image de sa figurine. J'ai donc conçu un réseau de neurones à convolution (CNN). Pour l'entraînement j'ai utilisé des images trouvées sur internet et des photos que j'ai moi-même prises. J'ai obtenu un taux de précision d'environ 90%. Pour utiliser le réseau de neurones, j'ai créé une petite application avec Streamlit pour ouvrir une image et afficher la prédiction.The idea was to build a neural network able to identify the type of a Skylanders character from a picture of its figurine. I designed a convolutional neural network (CNN). For training, I used images found online and photos I took myself. I reached an accuracy of about 90%. To use the network, I built a small Streamlit app that opens an image and displays the prediction.

Recherche sémantique de livreSemantic book search

Projet PersonnelPersonal project

Le but était de mettre en pratique l'embedding (transformer un texte en vecteur) et de créer un moteur de recherche de livre (rechercher les vecteurs les plus proches). Pour cela j'ai utilisé une base de données de plus de 16000 titres de livre avec leur résumés sur Kaggle. J'ai utilisé Streamlit pour l'interface.The goal was to practice text embedding (transforming text into vectors) and create a book search engine (by searching for the closest vectors). To do this, I used a dataset of over 16,000 book titles with their summaries from Kaggle. I used Streamlit for the interface.

Motion Capture SportifSports Motion Capture

Projet de groupe (4 personnes)Group project (4 people)

Le but était d'utiliser des outils déjà existants pour appliquer le motion capture sur sportif en mouvement. Puis, on devait mettre au point un réseau de neurones capable de prédire la suite du mouvement si on s'arrêtait au milieu de l'action.The goal was to use existing tools to apply motion capture to an athlete in motion. Then, we had to develop a neural network capable of predicting the rest of the movement if the action was stopped midway.
